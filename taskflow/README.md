# TaskFlow

TaskFlow — демонстрационный браузерный список личных задач на HTML, CSS и чистом JavaScript. Приложение работает как статический сайт; сервер, сборщик и сторонние библиотеки не нужны.

## Запуск

Откройте `index.html` в браузере. Для локальной разработки запустите Live Server в VS Code. На GitHub Pages проект будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/taskflow/`.

## Возможности

- Добавление задач кнопкой или Enter, валидация пустого названия.
- Изменение названия, удаление и переключение статуса.
- Фильтры «Все», «Активные», «Выполненные» и поиск.
- Счётчики, прогресс и понятные пустые состояния.
- Удаление выполненных задач с подтверждением.
- Автосохранение в `localStorage`, обработка повреждённых и недоступных данных.
- Клавиатурная навигация, видимый фокус, адаптация и `prefers-reduced-motion`.

## Структура данных

Задача — объект `{ id, title, completed, createdAt, updatedAt }`. Идентификатор уникален, даты — ISO-строки, `completed` — булево значение. Массив хранится под ключом `taskflow.tasks.v1`. При чтении проверяется формат; ошибочные данные очищаются, а недоступность хранилища не останавливает приложение.

## JavaScript

В `js/main.js` состояние задач отделено от отображения. `loadTasks` и `saveTasks` работают с хранилищем, `getVisibleTasks` применяет фильтр и поиск, `render` обновляет DOM и счётчики. Делегирование событий обслуживает отметку, изменение и удаление. Ввод отображается через `textContent` и DOM API, не через `innerHTML`.

## Навыки

Семантический HTML, CSS Grid/Flexbox, DOM и формы, валидация, `localStorage`, доступность и обработка пустых/ошибочных состояний.
