# Портфолио Ярослава Закирова

Статический сайт-портфолио начинающего frontend-разработчика и три самостоятельных демонстрационных проекта. Сборка и backend не нужны: GitHub Pages отдаёт готовые HTML, CSS, JavaScript и SVG-файлы.

## 1. Описание проекта

Главная страница представляет услуги, учебные проекты и контактные способы связи. Для каждого проекта доступны отдельная демо-страница и кейс с описанием реализации. В репозитории находятся:

- **North Coffee** — адаптивный концепт сайта независимой кофейни.
- **TaskFlow** — менеджер задач с поиском, фильтрацией и хранением в `localStorage` браузера.
- **WebCost** — демонстрационный калькулятор предварительной оценки стоимости веб-разработки.

Это портфолио и учебные демонстрации, а не сайты реальных организаций или коммерческие сервисы.

## 2. Возможности

- Адаптивная главная страница с переключением светлой и тёмной темы.
- Навигация по секциям и ссылки на демо и кейсы.
- North Coffee: мобильное меню, карточки напитков с диалоговым окном, демонстрационные адрес и цены.
- TaskFlow: создание, редактирование, удаление и фильтрация задач, поиск и локальное сохранение.
- WebCost: пересчёт ориентировочной стоимости по параметрам формы и сброс настроек.
- Локальные запасные изображения для фотографий North Coffee, если изображения Unsplash недоступны.

## 3. Технологии

- Семантический HTML5.
- CSS3, Grid, Flexbox и media queries.
- Vanilla JavaScript без библиотек и фреймворков.
- `localStorage` только в приложении TaskFlow.
- SVG для favicon и запасного изображения кофейни.
- Google Fonts и фотографии Unsplash загружаются из внешних источников; сборщика, backend, базы данных и серверных API в проекте нет.

## 5. Локальный запуск

Сборка не требуется. Самый надёжный способ — запустить простой статический HTTP-сервер из корневой папки репозитория.

**Windows с установленным Python:** откройте PowerShell в папке проекта и выполните:

```powershell
py -m http.server 8000
```

Затем откройте <http://localhost:8000/>. Чтобы остановить сервер, нажмите `Ctrl+C` в PowerShell. Также можно открыть корневой `index.html` напрямую или использовать расширение Live Server в VS Code. HTTP-сервер удобнее для проверки `localStorage` и поведения, близкого к опубликованному сайту.

## 6. Публикация на GitHub Pages

В Git-remote этого рабочего копирования настроен репозиторий `fsdfsdfsdf137-ai/fsdfsdfsdf137-ai.github.io`, основная ветка — `main`. Для специального репозитория GitHub Pages адрес сайта обычно имеет вид <https://fsdfsdfsdf137-ai.github.io/>. Настройки публикации и состояние последнего деплоя из локальной папки проверить нельзя.

1. Сохраните изменения и отправьте их в ветку `main` репозитория `fsdfsdfsdf137-ai/fsdfsdfsdf137-ai.github.io`.

   ```powershell
   git add .
   git commit -m "Prepare portfolio for GitHub Pages"
   git push origin main
   ```

2. На GitHub откройте репозиторий → **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Установите ветку **main** и папку **/(root)**, затем нажмите **Save**. GitHub Pages будет обслуживать файлы напрямую; workflow, npm и команда сборки не нужны.
5. Дождитесь завершения публикации в **Actions** или на странице **Settings → Pages**, затем откройте показанный GitHub адрес.
6. Проверьте главную страницу, демо North Coffee, TaskFlow и WebCost, страницы кейсов, favicon и вкладку Console/Network браузера. Убедитесь, что локальные CSS, JavaScript и изображения получают успешный ответ.

Если разместить тот же репозиторий как обычный проектный сайт, адрес будет включать имя репозитория: `https://<логин>.github.io/<репозиторий>/`. Пути в страницах оставлены относительными, поэтому этот префикс не должен требовать правок ссылок. Для обычного репозитория в настройках Pages также укажите **main** и **/(root)**.

## 7. Ограничения и известные проблемы

- Доступность внешних ресурсов и ссылок (Google Fonts, Unsplash, GitHub, Telegram и почта) из этой проверки не подтверждалась сетевыми запросами. Шрифты имеют системные запасные варианты; при недоступности удалённых фотографий North Coffee показывает локальный SVG-заполнитель. Если внешняя ссылка важна перед публикацией, откройте её вручную после деплоя.
- Фотографии кофейни загружаются с `images.unsplash.com`. Для максимальной надёжности можно скачать выбранные изображения в `north-coffee/assets/`, проверить условия лицензии/атрибуции и заменить удалённые URL локальными путями.
- Добавлена SVG-иконка сайта; отдельная ICO-версия не предусмотрена.
- TaskFlow хранит данные только в `localStorage` текущего браузера. Нет аккаунтов, синхронизации между устройствами или серверной копии.
- WebCost выдаёт демонстрационную оценку, а не оферту или гарантированную смету.
- North Coffee — учебный концепт: адрес, часы работы, меню и цены демонстрационные; реального заказа, бронирования и оплаты нет.
- В портфолио опубликованы контактные адреса, указанные в HTML. Перед открытием репозитория проверьте, что согласны показывать их публично.
- Выполнена статическая проверка относительных ссылок, локальных ресурсов, якорей и абсолютных локальных путей в HTML/CSS. Приложения не запускались в браузере, адаптивность на физических устройствах и внешние URL здесь не проверялись; успешная публикация GitHub Pages не подтверждена.
