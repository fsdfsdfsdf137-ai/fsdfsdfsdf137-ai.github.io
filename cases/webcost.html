Контекст и решение

Показать из чего складывается ориентировочная стоимость

Задача

Сделать демонстрационный инструмент для выбора состава веб-проекта и мгновенной оценки, не создавая впечатление официальной сметы или обещания фиксированной цены.

Решение

Ставки и коэффициенты собраны в одном объекте конфигурации. Форма пересчитывает сумму при каждом изменении, а тёмная панель результата показывает отдельные составляющие и предупреждает о демонстрационном характере расчёта.

F · Техническая реализация

Форма управляет параметрами, конфигурация — ценами

Файлы реализации: index.html · css/style.css · js/main.js.

Структура HTML

Форма содержит select для вида проекта и сложности, числовое поле количества, группу чекбоксов функций и radio-сроки. У каждого поля есть label; ошибка, итог и детализация имеют отдельные текстовые области. Сброс сделан настоящей кнопкой type="reset".

Стили CSS

На широком экране форма и итоговая карточка стоят рядом в Grid. До 680 px колонки становятся вертикальными, до 420 px сами поля тоже выстраиваются в одну колонку. Кликабельные варианты показывают hover и focus.

Расчёт и конфигурация

Один объект PRICING хранит базовые цены, стоимость единицы, ставки функций, коэффициенты сложности/срочности и границы количества. Сумма считается из выбранного состояния, не через eval и не из чисел, спрятанных в обработчиках.

const baseSubtotal = project.base
  + quantity * project.unitPrice
  + featuresCost;
const complexityTotal = Math.round(
  baseSubtotal * complexity.factor
);
const finalTotal = Math.round(
  complexityTotal * urgency.factor
);

События и DOM

Форма слушает input и change, поэтому результат обновляется при наборе количества, смене выбора и отметке функции. Строки расшифровки создаются createElement и получают данные через textContent. Для рублей применяется Intl.NumberFormat.

Валидация и ошибки

Количество должно быть целым числом в пределах 1–60. Пустое, отрицательное, дробное и выходящее за пределы значение скрывает итог, показывает сообщение и ставит aria-invalid. При валидном вводе ошибка снимается.

Сброс и согласованность

Событие reset откладывает пересчёт до применения браузером начальных значений полей. Итог складывается из показанных строк: базовой суммы, количества, функций и округлённых надбавок.

Хранение данных

Не используется. Выборы существуют только в текущей форме и не отправляются на сервер, не сохраняются и не обрабатываются платёжной системой.

Адаптивность и доступность

Есть skip-link, label, fieldset/legend, live-сообщение об ошибке и live-итог. Клавиатурное управление обеспечивает нативная форма; пользовательские checkbox/radio имеют видимый focus. CSS учитывает prefers-reduced-motion.

G · Адаптивность и UX

Параметры рядом с мгновенным результатом

На широком экране форма и оценка видны одновременно, что упрощает сравнение выбора с ценой. На телефоне сначала идёт форма, затем карточка с итогом и расшифровкой. Дополнительные опции можно комбинировать, срочность выбирается как один из двух взаимоисключающих вариантов. Сброс возвращает исходные значения, а ошибки не оставляют устаревший итог на экране.

Показанные суммы демонстрационные: калькулятор не рассчитывает договорную стоимость, не обещает срок и не отправляет заявку.

I · Чему научился

Навыки форм и вычислений

Форма и состояние

  • Связь label, select, number, checkbox и radio.
  • Обработка событий input, change и reset.
  • Валидация количества и доступное сообщение.
  • Пересчёт отображения при изменении состояния.

Расчёты и интерфейс

  • Конфигурация тарифов вместо рассыпанных чисел.
  • Округление промежуточных сумм.
  • Форматирование рублей через Intl.NumberFormat.
  • Построение безопасной DOM-расшифровки и проверка сценариев.
J · Что можно улучшить

Следующие шаги для более точной оценки

Подробные параметры сложности

Заменить один общий коэффициент несколькими понятными факторами, например сложностью интерфейса и интерактивностью. Это объяснит пользователю влияние каждого выбора.

Сохранение или печать расчёта

Добавить экспорт локальной сметы в печатный вид. Пользователь сможет вернуться к выбранной комбинации без отправки данных на сервер.

Тесты в реальном браузере

Добавить автоматизированные проверки формы и пройти ручной аудит клавиатуры и мобильных размеров. Это дополнит уже выполненные unit-проверки арифметики.

K · Итог

Предварительная оценка с прозрачной расшифровкой

WebCost рассчитывает демонстрационную стоимость по типу и объёму проекта, функциям, сложности и сроку. Проект показывает формы, валидацию, обработку событий, форматирование валюты и согласованную расшифровку. Ограничения: цены условны, техническое задание не анализируется, расчёт не является офертой; browser/device проверка пока не запускалась.
