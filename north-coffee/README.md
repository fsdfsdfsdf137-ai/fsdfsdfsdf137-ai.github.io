# North Coffee

Адаптивный демонстрационный сайт современной независимой кофейни на HTML5, CSS3 и чистом JavaScript. Это учебный концепт: адрес, расписание, меню и цены вымышлены и явно отмечены как демонстрационные. Бронирования и оплаты на сайте нет.

## Архитектура

- `index.html` — семантические секции страницы, навигация, карточки напитков и нативный `<dialog>`.
- `css/style.css` — палитра, типографика, mobile-first сетки, состояния фокуса, адаптивные точки 350/431/681/901 px и анимации.
- `js/main.js` — мобильное меню, карточки с описаниями, управление диалогом и фокусом, fallback изображений, появление блоков при прокрутке.
- `assets/photo-placeholder.svg` — локальная иллюстрация, подставляемая, если внешнее фото недоступно.

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер из папки `north-coffee`:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/north-coffee/` из корня сайта или `http://localhost:8000`, если сервер запущен непосредственно в папке проекта.

## Изображения

Фотографии загружаются с Unsplash по прямым ссылкам после попадания изображения в область просмотра. До успешной загрузки показывается локальный `assets/photo-placeholder.svg`, поэтому офлайн-режим и ошибки сети не ломают макет. Изображения Unsplash доступны по Unsplash License.

Чтобы заменить фото на свои, положите файлы в `assets/`, например `hero-coffee.jpg`, `espresso.jpg`, `flat-white.jpg`, `filter-coffee.jpg`, `interior.jpg`, `barista.jpg`, `coffee-beans.jpg`, затем у соответствующего `<img>` замените `src` на `assets/имя-файла.jpg` и удалите атрибут `data-photo`. Сохраните подходящий `alt`; используйте фотографии, на которые у вас есть права. Источники Unsplash приведены в `index.html`.

## Функции

- Адаптивная навигация с корректным `aria-expanded`; меню закрывается по выбору раздела, клику снаружи и Escape.
- Плавная прокрутка по якорям.
- Карточки напитков открывают доступное модальное окно с описанием.
- Диалог закрывается кнопкой, по Escape и клику на фон; фокус возвращается на активированную карточку, прокрутка страницы блокируется на время показа.
- Безопасный fallback изображений и анимации появления блоков при прокрутке.
- Соблюдение `prefers-reduced-motion`, видимый клавиатурный фокус и alt-тексты изображений.
