# WebCost

WebCost — демонстрационный калькулятор предварительной оценки веб-разработки на HTML, CSS и Vanilla JavaScript. Это статический проект без backend, сборщика и сторонних библиотек.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер из корня проекта, например Live Server в VS Code. На GitHub Pages после публикации репозитория проект будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/webcost/`.

## Как считается стоимость

Формула состоит из последовательных этапов:

1. Базовая цена типа проекта + число страниц/блоков × ставка за единицу + выбранные дополнительные функции.
2. К сумме применяется коэффициент сложности.
3. К полученной сумме применяется коэффициент срочности.

Сумма после каждого коэффициента округляется до целого рубля. Поэтому отдельные строки расшифровки складываются в показанный итог без разницы на округлении. Все тарифы и коэффициенты собраны в объекте `PRICING` в `js/main.js`. Цены демонстрационные, расчёт не является офертой.

## Как менять цены

В объекте `PRICING` измените `base` и `unitPrice` в нужном типе проекта; ставки доп. функций находятся в `features`, коэффициенты — в `complexity` и `urgency`. Форматирование валюты использует `Intl.NumberFormat` и настройки `locale`/`currency` в конфигурации.

## Как добавить услугу

- Новый тип проекта: добавьте в `PRICING.projects` объект с `label`, `base`, `unitPrice`, `unitSingular`, `unitFew`, `unitPlural`, `hint`, а также `<option>` с таким же `value` в `index.html`.
- Новая функция: добавьте объект с `label` и `price` в `PRICING.features`, затем чекбокс `name="feature"` с соответствующим `value` в `index.html`.
- Новый уровень сложности или срок: добавьте метку и коэффициент в соответствующий раздел конфигурации и вариант `select` или `radio` с тем же `value` в HTML.

## Возможности и навыки

Расчёты на основе конфигурации, обработка и валидация формы, управление состоянием полей, форматирование валюты, доступные сообщения об ошибках, DOM API без небезопасной вставки HTML, адаптивный CSS Grid/Flexbox и `prefers-reduced-motion`.
